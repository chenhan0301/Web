# Web｜112-1 網際網路概論學習紀錄

> **University Learning Journey · Year 2 / 2023**  
> 我的第一個 GitHub 課程紀錄，也是我從「寫程式」走向「把作品公開部署」的起點。

## About this repository

這個 repository 記錄我在國立臺灣師範大學科技應用與人力資源發展學系「網際網路概論」課程中的學習歷程。

大二以前，我對程式的理解主要停留在單機環境中的程式邏輯；這門課第一次讓我完整接觸 **開發環境、版本控制、前端介面與網站部署**。從建立 Node.js / VS Code 環境，到使用 GitHub Desktop、Bootstrap、CSS 與 JavaScript，我開始把程式做成別人可以直接開啟與使用的網頁。

這個階段後來成為我學習資料分析、資料庫系統，以及建置 LexiAI 報表介面的基礎。

## Learning reflection

這門課對我的影響不只是一個網站。

它讓我第一次理解：**程式的價值不只在於能執行，也在於能否被使用者看見、操作與理解。**  
後來不論是資料庫系統的前端頁面，或 LexiAI 的人才適任性分析報表，我都持續把「資訊如何被呈現」視為系統設計的一部分。
